CrestPrime is a real-time data processing framework that leverages auto-scaling to optimize processor utilization.

With CrestPrime, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/CrestPrime.git`
2. `cd CrestPrime`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure CrestPrime, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
